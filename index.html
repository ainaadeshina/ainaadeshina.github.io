Family Finance Planner

Family Finance Planner is a private, personal desktop tool used by a single household to organise its own finances. It is not offered to the public.

Privacy Policy

Last updated: 20 November 2026

What data the app accesses

With the account owner's consent, the app uses the Gmail API with the read-only scope (gmail.readonly) to read emails in the owner's own Gmail account, such as bank alerts and receipts, in order to record household transactions.

How the data is used

Email content is processed only on the owner's own computer to build the household's financial records. The app never sends, deletes, or modifies emails.

Storage and sharing

Data stays on the owner's local machine. It is not sold, shared with third parties, used for advertising, or used to train AI or machine-learning models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
